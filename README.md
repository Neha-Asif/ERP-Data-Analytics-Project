# ERP Data Analytics Project

📊 Project Overview

This project focuses on transforming raw ERP data into meaningful business insights through a complete data analytics workflow.

The project covers data profiling, data cleaning, ETL, SQL database development, business analysis, and Power BI dashboard development. The goal is to prepare unclean business data, analyze it using SQL, and present key findings through an interactive executive dashboard.

🎯 Objectives

* Analyze and understand raw ERP data
* Identify and resolve data quality issues
* Clean and transform data for analysis
* Build a structured SQL database
* Design an Entity-Relationship Diagram (ERD)
* Perform business analysis using SQL queries
* Develop an interactive Power BI dashboard
* Generate meaningful business insights from the data

🛠️ Tools & Technologies

* **Power Query** – Data cleaning and transformation
* **SQL / SQL Server** – Database development and analysis
* **Power BI** – Data modeling, visualization, and dashboard development
* **DAX** – Calculations and analytical measures
* **CSV** – Source and cleaned datasets
* **ER Diagram** – Database relationship modeling

📁 Project Components

Data Preparation

The raw ERP dataset was profiled, cleaned, and transformed to improve data quality and prepare it for analysis.

ETL

An ETL workflow was used to extract, transform, and prepare the data for structured analysis.

SQL Database

A relational database structure was developed to organize the ERP data and establish relationships between relevant entities.

ER Diagram

An Entity-Relationship Diagram was created to visually represent the database structure and relationships.

SQL Analysis

Business-focused SQL queries were developed to analyze the data and answer relevant analytical questions.

Power BI Dashboard

An interactive Power BI dashboard was developed to visualize important KPIs, trends, and business performance indicators.

Business Insights

The analysis was used to identify important patterns and generate insights that can support data-driven business decisions.
